# Icons

Icons people made for RadialDeck slices. Each one is a picture file in this folder, and the gallery at
[radialdeck.com/icons.html](https://radialdeck.com/icons.html) shows everything that is here.

## Using one

Download it, then in RadialDeck open Settings, pick a slice, press the **…** next to Icon and drop the file on
that window. It is copied into **My icons** (`%APPDATA%\RadialDeck\icons`) and stays there.

## Sending yours

1. Make it in the [icon studio](https://radialdeck.com/icons.html#studio), or bring your own.
2. Open the [upload page for this folder](https://github.com/StefanKasamakov/radialdeck-themes/upload/main/icons),
   drag the picture in and choose **Propose changes**. GitHub turns it into a pull request.

What makes it in:

- PNG with a transparent background, 256×256 (ICO, JPG and GIF also work).
- A short, lowercase file name with hyphens: `invoice-stamp.png`, not `IMG_0042.png`.
- It has to read at 28 pixels, the size a slice draws it.
- Your own work, or something you are free to share. No company logos you do not own.
